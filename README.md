# 個体値ぶっこみスキャン

*for Pokémon Sleep*

Pokémon Sleep の「おてつだい能力」スクリーンショットを複数枚まとめて解析し、CSVへ変換するブラウザツールです。

`v12-final` は、実機検証済みの `v12-beta2` と `v12-final-candidate` を基準に、**認識・要確認ロジックを変更せず**正式版として固定したものです。

## 起動方法

Windowsでは `start_server.bat` を実行してください。ブラウザで `http://localhost:8019/` が開きます。

## v12で追加された機能

### 1. まっしろミント対応

通常の性格補正で `NO_EXACT_MATCH` の場合だけ、性格欄右端の緑色マークを画像特徴で確認します。

次の3条件がそろった場合だけ、表示上の性格名を保持しつつ性格補正をneutralizedとして採用します。

1. 通常計算が `NO_EXACT_MATCH`
2. まっしろミントマークを検出
3. 性格補正だけ `speed / energy / ingredient / skill = 1.0` にした計算が `UNIQUE`

検証サンプル `1000004928.png` では、表示性格「おだやか」を保持したままフライゴンへ一意一致しました。

### 2. 低margin食材の要確認

食材ランキング自体は変更せず、画像判定で1位と2位の差が `0.015` 未満の場合だけ `needsReview` とします。

要確認枠は最初に「要確認: 候補を選択」と表示します。現在のpokesleep-tool互換CSVでは、未確定食材が残っている場合はCSV保存/コピーを止め、該当食材の確定を求めます。ユーザーが候補を明示選択した場合だけ確認済みとなり、選択した食材をCSVへ出力します。
せいかくが未確定・要確認のままの場合も、pokesleep-tool側で別の性格として解釈されることを防ぐためCSV保存/コピーを止め、先に確定を求めます。

検証サンプル `1000004931.png` のLv.60食材では、1位「ずっしりカボチャ」、2位「ほっこりポテト」、margin `0.009496...` のため要確認となり、正解の「ほっこりポテト」を手動確定できることを確認済みです。
